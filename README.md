# 🛒 Shopping List App

A responsive shopping list web application built with **React + TypeScript**, **Redux Toolkit**, and **JSON Server**.

The application allows users to register, log in, create and manage shopping lists, organise items by category, and search/sort lists using URL parameters.

## 🎯 Objective

Build a shopping list application using **ReactTS** and **JSON Server** that allows users to create and track different shopping lists using **Redux** for state management, while following proper web application navigation practices.

## ✨ Features

### Authentication & Profile

* User registration and login
* Secure credential handling
* Protected routes
* View and update profile
* Update login credentials

### Shopping Lists

* Create multiple shopping lists
* Add item name, quantity, category, notes and images
* View shopping lists
* Edit shopping lists and items
* Delete shopping lists and items
* Categorise items

### Search & Sorting

* Search items by name
* Filter and sort shopping lists
* Sort by:

  * Name
  * Category
  * Date added
* Search and sorting parameters are reflected in the URL
* URL changes automatically update the displayed results

### UI & Responsiveness

* Notifications and feedback for user actions

## 🚀 Installation

```bash
git clone https://github.com/SenseiTumelo/Task-4-Shopping-List-App.git
cd shopping-list-app
npm install
```

Start JSON Server:

```bash
npm run server
```

Start the application:

```bash
npm run dev
```
